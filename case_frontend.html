Собрать страницу каталога

Покажите, как вы превращаете требования продукта в работающий интерфейс.

Стажёр Frontend-разработчикДо 2 часов

Ситуация

В каталоге нужно показать список услуг, полученный от API. Считайте, что API возвращает массив объектов с полями name, description и price. Макета и готового API нет.

Задача

Сделайте небольшой адаптивный экран каталога. Можно использовать любой знакомый стек или чистые HTML, CSS и JavaScript.

  1. Покажите карточки услуг с названием, кратким описанием и ценой.
  2. Предусмотрите состояния загрузки, пустого списка и ошибки.
  3. Сделайте интерфейс удобным на узком мобильном экране.
  4. Кратко объясните структуру решения и как его проверить.

Что отправить

Ссылку на работающий прототип или файлы проекта и короткую инструкцию. Если не успеваете сделать всё, опишите оставшиеся шаги и свои допущения.

Критерии оценки

  • Рабочее решение и обработка состояний — 35%.
  • Структура и понятность кода — 25%.
  • Адаптивность и удобство интерфейса — 20%.
  • Объяснение решения и инструкции — 20%.
